# Coding-Decoding Questions

## 1. Code for REQUIRED

### Original question

In a certain code CERTAIN is XVIGZRM and SEQUENCE is HVJFVMXV. How would REQUIRED be coded?

### Approach

The examples use reverse-alphabet substitution (Atbash): A maps to Z, B to Y, C to X, and so on. This verifies both examples.

### Calculation

$$
R\to I,\ I\to R,\ Q\to J,\ U\to F,\ I\to R,\ R\to I,\ E\to V,\ D\to W
$$

Therefore:

$$
\text{REQUIRED}\to\text{IRJFRIVW}
$$

### Final answer

**IRJFRIVW**.
