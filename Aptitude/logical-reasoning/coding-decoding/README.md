# Coding-Decoding

## Definition and scope

Coding-decoding questions replace letters or words using a consistent transformation. Identify the mapping from the examples and apply it to the target word.

## Method

Compare corresponding letters, test common transformations such as alphabet reversal, and verify the rule against every supplied example.

## Common trap

A rule must explain all examples, not just the first word. The Atbash transformation maps a letter to its reverse alphabet partner: A-Z, B-Y, and so on.
