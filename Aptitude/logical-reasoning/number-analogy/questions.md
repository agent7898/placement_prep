# Number Analogy Questions

## 1. Complete the analogy

### Original question

9643 : 11 :: 3278 : 10 :: 8976 : ?

### Approach

The output is half the sum of the four digits:

$$
\frac{9+6+4+3}{2}=11,\qquad \frac{3+2+7+8}{2}=10
$$

### Calculation

$$
\frac{8+9+7+6}{2}=\frac{30}{2}=15
$$

### Final answer

**15**.

### Note

This is the simplest rule consistent with both supplied examples.
