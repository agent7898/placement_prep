# Number Analogy

## Definition and scope

Number analogies express a numerical rule in the form $a:b::c:d$. The same operation or relation used for the first pair is applied to the second pair.

## Method

Test simple digit operations first: sum, difference, products, averages, and combinations of odd and even positions. Confirm the rule against all given pairs before applying it.

## Trap

Do not infer a rule from one pair alone when multiple pairs are supplied.
