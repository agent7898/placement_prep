# Logical Reasoning

Logical reasoning covers structured deduction and pattern-based problems used in placement assessments.

Typical topics include number and letter series, coding-decoding, analogy, classification, blood relations, directions, ranking, seating arrangements, puzzles, syllogisms, conclusions, assumptions, data sufficiency, and Venn diagrams.

For each asked topic, create a normalized topic folder. Keep rules, patterns, and solving frameworks in the topic README, then append explained solutions to `questions.md`.
