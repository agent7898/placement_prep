# Aptitude

Aptitude preparation focuses on speed, pattern recognition, accuracy, and clear reasoning for online assessments and placement interviews.

## Types

- [Quantitative Aptitude](quantitative/README.md): mathematics, arithmetic, algebra, geometry, probability, and numerical problem solving.
- [Logical Reasoning](logical-reasoning/README.md): patterns, arrangements, deductions, puzzles, and decision-making.
- [Verbal Ability](verbal-ability/README.md): vocabulary, grammar, comprehension, sentence correction, and verbal logic.
- [Data Interpretation](data-interpretation/README.md): tables, charts, graphs, comparisons, ratios, percentages, and caselets.

## Question workflow

When a question is asked, classify it into one type and identify its topic. Create a topic folder only when needed. Keep reusable theory and formulae in the topic README, and append solved questions to that topic's `questions.md` file.

Each solution should preserve the original question, explain the approach, show calculations or reasoning, state the final answer, and record traps or lessons learned.
