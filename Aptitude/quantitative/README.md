# Quantitative Aptitude

Quantitative aptitude covers numerical and mathematical problem solving required in placement assessments.

Typical topics include number systems, divisibility, HCF and LCM, percentages, profit and loss, interest, ratios, averages, time and work, speed and distance, algebra, geometry, probability, permutations and combinations, clocks, calendars, and ages.

For each asked topic, create a normalized topic folder such as `hcf-lcm/`. Keep formulas and reusable methods in the topic README, then append worked problems to `questions.md`.
