# Placement Preparation Workspace Guidelines

This repository is a placement-preparation handbook organized into four categories:

- `Aptitude`
- `coreCS`
- `coreJava`
- `systemArchitecture`

## Mandatory routing

Before answering a question or changing files:

1. Classify the question into exactly one category.
2. Read and follow the matching category guidance in `.github/instructions/`.
3. Use the existing handbook and nearby notes as the source of truth for structure and terminology.
4. Keep generated content accurate, structured, placement-focused, and useful for revision or interview practice.

Use the dominant category when the intent is clear. Ask one concise clarification when the category is genuinely ambiguous. Do not silently duplicate one question across multiple categories.

## File and content conventions

- Preserve existing notes and naming conventions unless a change is required.
- Prefer focused Markdown files over large unrelated edits.
- Use headings, tables, bullets, examples, and KaTeX-compatible math where appropriate.
- Explain reasoning, not only final answers.
- For calculations, show units, intermediate steps, assumptions, and a quick verification when useful.
- Do not create an aptitude topic folder until a question identifies the topic.
- Append new practice questions to the relevant question log; do not replace earlier solutions.
