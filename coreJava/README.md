# Core Java

Core Java preparation covers the language fundamentals and standard library knowledge expected in placement assessments and technical interviews.

## Scope

- Java syntax, types, operators, control flow, arrays, and strings
- Classes, objects, inheritance, polymorphism, abstraction, and encapsulation
- Exceptions, packages, generics, and file handling
- Collections, iterators, `Comparable`, and `Comparator`
- Lambdas, streams, and modern Java basics
- Introductory concurrency and common runtime behavior

## Study approach

Move from definition to syntax to a small example to runtime behavior and interview traps. Include time and space complexity for collection operations and algorithms. Existing notes such as [Java Collections Framework](java_collections_framework.md) and [Java OOP Checklist](java_oops_checklist.md) are the primary local references.
